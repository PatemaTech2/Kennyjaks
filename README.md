# Kennyjaks

A Jujutsu Kaisen inspired RPG for WhatsApp and Telegram

## Features

- Turn-based combat system with skill-based moves
- Enemy spawning and battling system
- Progression system with XP, levels, and grades
- Economy system with Yen and Ken tokens
- Inventory management and shop
- Cross-platform support (WhatsApp & Telegram)

## Setup

1. Install dependencies: `npm install`
2. Set up environment variables in `.env`
3. Run the bot: `npm start`

## Commands

- Use `/start` to begin your journey
- Use `/menu` to see all available commands
- Use `/spawnenemy` to encounter a curse
- Use `/fight` to engage in battle
